PERSONAL CLOUD AGENT

把云机与 Agent，放进自己的环境

面向个人使用的私有化部署方案：自己管理设备、任务与数据，从任意一端进入同一个 Agent 工作台。

01 / 环境

部署在自己的主机

在个人电脑、私有服务器或自有云主机运行服务，由自己管理连接地址与访问权限。

02 / 数据

设备与任务由自己管理

统一连接个人 Android 设备与云机，脚本、截图、录像和任务记录保存在自己的部署环境。

03 / 模型

按需要连接 AI 模型

Agent 规划支持接入自部署模型或指定模型服务。使用外部模型时，任务上下文按配置发送到该服务。

CURRENT CAPABILITIES

已有设备能力，构成 Agent 的基础

当前项目已具备画面查看、设备操作、状态检查与扩展接口，为个人云机 Agent 提供感知和执行基础。

实时投屏与控制

浏览器直接查看 Android 画面，支持鼠标、触摸、键盘、旋转、全屏与画中画。

多设备监控

设备列表与大屏模式集中呈现多台设备，快速切换目标并查看状态。

播放器检查器

取色、坐标、XML 树、XPath 和页面信息联动，帮助定位屏幕元素。

文件与模板管理

管理设备共享存储；保存和整理截图模板，供外部识别流程使用。

录屏与回放

保存 MP4 录制，查看历史记录，并将录制画面回放到投屏与 Vision 通道。

扩展与脚本管理

提供 ADB 终端、Python Vision 接口及 Python 脚本的分类和在线编辑。

AGENT WORKFLOWS

给云机一个目标，让 Agent 完成任务

Markdown 沉淀可复用流程，AI 根据目标和设备状态组织行动。每次执行都能查看步骤、验证结果并保留记录。

以下为新增功能规划
01 · 可复用步骤 规划中

Markdown 脚本

用可阅读的文档组织任务说明、设备步骤与检查点。编辑时预览，运行前确认目标设备和动作。

编写步骤→校验动作→确认设备→运行记录
适合重复巡检、操作指引和团队共享的标准流程。
02 · 自然语言任务 规划中

AI 脚本执行

描述目标，Agent 结合当前画面与可用动作生成计划，执行后检查状态并反馈结果。过程可查看，支持随时停止。

描述目标→生成计划→人工确认→逐步执行
适合探索式任务；先审阅计划，再由 Agent 执行和验证。
SCRIPT STUDIO CONCEPT

脚本工作台的设计方向

沿用现有的脚本管理入口，补上文档化流程、AI 计划与执行过程的可视化。

一个任务，完整闭环

脚本内容、目标设备、执行步骤与结果放在同一视野中。

1选择在线设备，确认当前画面。
2编辑 Markdown 步骤，或让 AI 生成计划。
3审阅动作，运行后查看逐步记录。
