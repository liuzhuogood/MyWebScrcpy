# 页面观察与决策规则

1. **单轮观测绑定**：
   每次调用 `observe.py` 均返回一个唯一的 `observation_id`。所有截图、OCR 结果、模板匹配与 AI 决策结果均与该标识严格绑定。
2. **上下文稳定性**：
   `observe.py` 会在截屏前后核对前台 Package 与 Activity。若两者在观测期间发生切换，输出中的 `context_stable` 将为 `false`，助手需谨慎对待此瞬态画面。
3. **AI 决策中立性**：
   若未显式指定 `--goal`，AI 模型将以中立客观角度罗列可见控件和界面要素，不臆造或推测用户意图。
4. **决策结果不自动执行**：
   AI 决策建议仅作为外部助手规划下一步动作的参考依据，不得将其直接作为设备执行指令。
