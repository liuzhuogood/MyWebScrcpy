# 任务执行记录

在脚本文档中点击「执行记录」打开弹窗，选择运行批次和设备，查看该设备本次任务的日志、录制和报告。设备状态旁的「查看执行」直接打开对应任务。关闭弹窗后，文档草稿、助手会话和工作台布局仍保留。

一次手动或定时触发对应一个批次，每台设备对应独立任务。批次保存触发时的文档、版本、设备列表和配置快照；之后修改脚本不会改变历史记录。升级前的任务仍可查看原有状态，缺少的产物显示未采集。

## Markdown 头部

点击文档标题旁的信息按钮「头部配置说明」，查看参数、默认行为和可复制的完整示例。

| 参数 | 省略时 | 说明 |
| --- | --- | --- |
| `version` | 按修改时间生成版本 | 文档版本，如 `1.0.0`；建议修改步骤时同步更新。 |
| `schedule` | 不定时执行 | Cron：5 段“分 时 日 月 星期”，或最前面增加秒的 6 段；`0 9 * * *` 为每天 09:00。 |
| `timeout_sec` | 120 秒 | 执行超时，填写正整数秒数。 |
| `enabled` | `true` | 定时开关，需同时配置 schedule 和目标设备，不影响手动运行。 |
| `recording.enabled` | `false` | 开始自动录制、结束停止；失败仍继续任务。 |
| `recording.record_audio` | `false` | 同时录制声音，需开启录制且设备支持。 |
| `report.enabled` | `false` | 每设备执行结束后生成 AI 报告，需配置系统模型。 |
| `report.prompt` | 自动总结执行结果 | 最多 4000 字，使用 `|` 可换行；需开启报告。 |

这些默认值指省略参数时的行为，新建任务示例默认关闭定时、录制和报告。任务标题与目标设备在任务配置中设置；`name` 仅作标注，`target_device` 和 `target_devices` 不再作为头部参数。

录制和报告默认关闭。以下字段仅在文档开头由 `---` 分隔的 YAML 头部生效，正文示例不会触发录制或模型请求。

```yaml
---
version: 1.0.0
timeout_sec: 120
recording:
  enabled: true
  record_audio: false
report:
  enabled: true
  prompt: 总结执行结果、失败原因和需要人工确认的事项，引用日志证据。
---
# 步骤
- 等待 2 秒
```

开关必须为 `true` 或 `false`，不能写成字符串。`report.prompt` 最多 4000 个字符；重复键、别名和未知的录制/报告子字段会被拒绝。原有标量解析与不含扩展配置的旧文档继续保留。

## 日志

所有新任务持续采集标准输出、错误输出和生命周期事件。支持来源筛选、搜索、跟随、读取更早日志及下载 JSONL。日志序号属于单个任务；报告引用也使用此序号。

Python 使用无缓冲 UTF-8 输出。单行超过 16 KiB 时分段保存；无换行输出在管道关闭时仍保留。原始 JSONL 每任务最多 20 MiB，所有任务合计最多 1 GiB，不计小型状态与索引文件。达到上限后继续消费输出，界面显示截断；不会因管道阻塞而挂住 Python。运行前无法初始化日志时任务不会启动，运行中写入失败则保留已写日志并继续任务。

原始日志和索引在任务结束 7 天后到期，后台每分钟清理一次；重启时也清理。任务状态和报告保留。日志位于 SQLite 文件旁的 `<数据库文件>.artifacts/logs/`，备份数据库时应同时备份该目录。

## 录制

开启后，任务准备阶段尝试开始录制，准备最多等待 5 秒，Python 的执行超时从进程启动计算。失败、冲突或设备不支持时仍继续执行，录制状态保存原因。任务只停止自己拥有的录制，不接管已有手动录制。

Python 结束后请求停止录制，MP4 收尾独立进行。文件就绪后可播放、拖动和下载；媒体接口支持 Range 请求。若首个视频关键帧晚于 Python 启动、录制提前停止或缺少完整覆盖证据，会显示录制未覆盖完整执行。报告不分析视频。文件保留期沿用原有录制策略。

## AI 报告

开启报告后，每台设备任务结束时独立排队生成，使用系统保存的模型、地址和密钥。总结请求直接调用 OpenAI 兼容的 `/chat/completions`，不启动助手会话，不提供工具，也不读取其他任务。

输入包含本次状态、时间、退出码和有限日志证据，优先选择系统事件、错误输出及首尾片段，日志部分最多 60 KiB，执行错误等元数据过长时标记截断，完整证据 JSON 最多 64 KiB。脚本文档只提供版本和哈希，不发送全文。每次请求最多 60 秒，同时处理两份报告；失败不改变任务结果，也不自动反复重试。

「重新生成」创建新修订，使用第一次冻结的证据和报告要求。重试失败仍显示最后一份成功报告。服务重启后继续等待中的队列，正在生成的修订标为失败。引用必须属于提供给模型的日志片段；非法引用导致该次生成失败。HTML、图片和链接不会加载到报告界面。日志已过期时报告仍可查看和下载，引用跳转关闭。

## 升级与回退

升级前备份 SQLite、脚本文档、上述日志目录和现有录制目录。数据库仅增加产物、批次快照和报告表，旧接口、脚本文档及手动录制入口保留。启动时按明确任务与录制归属恢复；未结束的新任务会标为失败，确认进程命令包含保存的唯一脚本路径后才清理遗留进程。

回退前关闭新录制与报告触发，等待或明确终止后台任务，然后备份当前数据并回退配套前后端。若旧程序无法读取新增 schema，使用升级前备份恢复，另行保留新增产物。
