# v1.27.1：任务目录、统一状态与技能轻量化

## 核心变更

1. **任务中心与工作目录主动扫描**：
   - 外部任务使用标准化独立目录约定（`~/.mywebscrcppy/tasks/<task-id>/`），包含 `task.json`、`state.json`、`actions.jsonl` 及声明式产出文件（报告、日志、截图、视频）。
   - 任务中心移除自动轮询与后台 watcher，改为用户主动触发 `POST /api/task-runs/scan` 扫描并维护内存索引。
   - 严格依据产出声明安全读取文件，防路径穿越与媒体直出安全，业务成功与产出完整性独立记录与展示。
   - 定向升级 SQLite 数据库结构，彻底删除旧任务表及数据，保留设备、配置、操作日志与模板数据。
   - 彻底移除旧任务注册、心跳、日志上传、结束上报链路与 Python SDK `TaskReporter`。

2. **统一设备总状态与三类模板匹配**：
   - 提供 `GET /api/device-state/{serial}` 接口，单轮采集设备状态、页面信息、截图、UI XML、OCR 与模板匹配结果，绑定统一观测标识。
   - 支持三类模板来源同时匹配：全局启用模板、设备启用模板、关联任务技能模板。技能模板直接读取 `<skill-dir>/templates/`，来源同名隔离，不污染全局模板库。
   - 提供 Accept 区分的 JSON 与简单服务端 HTML 响应，无 level 参数，不另设额外路由。

3. **AI 服务配置与总状态决策**：
   - 系统设置扩展支持 OpenAI 兼容 Chat Completions 地址、显式模型名、密钥与超时配置。密钥严格服务端受控存储，读接口脱敏、日志不打印。
   - 提供 `POST /api/device-state/{serial}/decision` 接口，共用同一轮采集，依据官方视觉协议向 AI 模型发送截图与任务目标，输出页面摘要、可见控件、进展判断、下一步建议与依据，且决策结果不触发设备动作。
   - 采集 20s 预算，AI 30s 预算，全局最多 2 个 AI 请求并发，超额明确拒绝。

4. **通用操作技能与应用技能轻量化**：
   - 新增通用技能 `my-scrcpy-common`，提供标准化规则、Wiki 与共享操作脚本（观察页面、看视频、尝试返回、Android 返回、打开 APP、重启 APP），技能市场同步登记并支持校验。
   - 应用技能（快手等）全面精简，移除专用业务脚本与 dryrun，专注业务规则与页面 Wiki。
