# v1.3.1-fix 版本说明

> 基于 v1.3.0 的补丁版本。

1. 修正文件管理对象：从服务端本地文件改为连接手机上的文件。
2. 调整多手机使用方式：从投屏页面“更多”菜单打开文件管理弹窗，文件操作自动绑定当前已选手机。
3. 修复文件管理弹窗定位，使其在桌面端居中显示，并适配移动端窄屏滚动。
4. 补充横竖屏兼容性处理：区分投屏设备旋转能力与前台应用自身的方向锁定，避免将应用限制误判为投屏功能故障。
5. 移除前期不需要的令牌功能，包括 UI 令牌入口、令牌弹窗、前端令牌逻辑及服务端令牌鉴权设计。
6. 验证：Go 测试、`go vet`、Linux/Windows 构建、前端语法检查、发布工作流 YAML、服务冒烟和令牌清理检查已通过；真实 Android 设备文件操作、多手机切换、弹窗现场布局及横竖屏兼容性仍待生产设备验证。
