# v1.8.0-feature 版本摘要

1. **完全保留原有 WebSocket 协议**：维持既有 `/api/vision/stream`（视频流及动作/结果上行）和 `/api/vision/results`（检测结果广播）完全兼容，不影响任何现有自动化客户端。
2. **新增模板管理能力**：
   - 独立提供模板增删改查 RESTful 接口（`/api/templates`）。
   - 模板支持独立命名、区分设备绑定（设备特定或全局共享）、调整匹配参数（匹配阈值、多尺度、灰度、单项启用开关等）。
3. **区域截图直接转模板**：
   - 播放器区域截图工具栏新增“保存为模板”快捷入口，选区像素直接切片一键保存并持久化为匹配模板。
4. **状态与匹配查询**：
   - 支持实时获取模板匹配情况，返回命中目标的坐标（归一化与像素坐标）、模板名称及匹配度。
   - 提供模板匹配功能整机级/全局级一键开启与关闭接口。
5. **投屏绿框复用**：
   - 模板匹配结果标准化为 `detection.result`，无缝对接现有投屏 `detection-overlay`，实时在屏幕上高亮标注绿框与置信度。
