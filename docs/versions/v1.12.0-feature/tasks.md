- ✅ 2.1 【分割线占不满】重构 SplitLayout 增加常态 100% 全高垂直分割线，消除侧栏组件外层孤立圆角边框；通过 CDP 验证切换、拖拽及各面板贴合，分割线全高覆盖工作区。
- ✅ 2.2 【图标未统一】将全部基础组件迁移至 `lucide-vue-next`，移除 `@lucide/vue` 重复依赖；统一动作与尺寸规范。
- ✅ 2.3 【模板匹配不可用】收口至模板资产管理（CRUD、图片参考、ZIP 导入导出），清理失效 `/api/templates/matches` 轮询与 `/api/templates/click` 请求，文案与工具栏统一为模板管理。
- ✅ 2.4 【侧栏关闭与统一封装】封装 `SidePanelHeader` 组件，左上角固定提供关闭按钮；文件管理（嵌入模式）、模板管理、检查器、设置、重放控制、ADB Shell 统一接入；实现侧栏面板互斥打开与左上角关闭，通过 9222 CDP 实机自动化验证。
