4. GitHub Actions 的标签发布构建已接入前端编译；推送标签触发运行，实际结果以工作流为准。
5. 已完成 Vue 类型检查与生产构建、Go 测试与静态检查，并部署到 `10.0.0.6`，验证页面、资源和设备列表。
