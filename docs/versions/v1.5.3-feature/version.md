# MyWebScrcpy v1.5.3-feature

## 状态

代码实施完成并已部署至 `10.0.0.6`。已通过全量 Go 测试、构建、前端脚本语法和 Android 12 真机 AAC 采集/双轨 MP4 验收；线上 HTTPS WebSocket 与有声录像导出的 H.264/AAC 双轨均已复验。人工听感与更多 Android 版本覆盖留作后续兼容性验证。

## 计划能力

1. 网页端可接收 Android AAC 音频、按设备 PTS 播放，并提供默认静音的声音开关。
2. 创建录制时可选择写入设备音频；录像详情与历史记录显示是否含声音。
3. 有声录像使用 H.264 + AAC 双轨 MP4；音频不可用或中断时明确失败，不会静默生成无声录像。

## 兼容策略

- 未传 `record_audio` 的既有调用保持无声录像。
- 不支持设备音频转发的 Android 设备继续支持投屏与无声录像。
- 本版本不改变设备端扬声器策略，也不采集浏览器麦克风。
