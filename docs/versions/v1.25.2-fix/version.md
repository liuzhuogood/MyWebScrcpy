# v1.25.2：小窗无边框、顶栏恢复与 OCR 集成

## 变更

- 原生投屏小窗新增无边框开关，可从窗口菜单或投屏设置侧栏隐藏系统标题栏；系统投屏设置可保存新小窗的默认值。
- 隐藏小窗顶栏时显示恢复提示；恢复小窗时同时恢复顶栏、系统标题栏、透明度和鼠标输入，拒绝恢复前排队的旧设置请求。
- 接入 Indra OCR，统一管理 OCR 和模板匹配所需的 Python 运行环境、依赖准备及服务开关偏好；补充接口、SDK 和使用文档。
- 调整播放器检查器 OCR 交互和结果有效性检查，保留交互原型与回归用例。
- 检查面板默认保持屏幕操控，显式进入检查模式后才拦截输入；选区完成后恢复操控，连续 OCR 保持同一区域。
- 新增设备自动化脚本技能，调整原型公网预览配置，整理历史会话记录和本地开发配置。

## 本地验证

- 干净源码副本的 Go 全套测试、`go vet`，以及 OCR、模板匹配、服务偏好和 Python 环境管理的竞态测试通过。
- 前端与原型类型检查、构建、19 项 Node 测试、小窗并发恢复及 OCR 选区回归通过。
- Python SDK 43 项测试、两个 OCR sidecar 共 8 项测试、视觉脚本 5 项测试及自动化脚本 7 项离线测试通过；SDK wheel、sdist 构建与严格元数据检查通过。
- macOS 原生小窗回归验证无边框开关、默认值、隐藏顶栏提示、恢复与重新打开、系统窗口装饰和过期请求拒绝。
- 浏览器使用正式检查器与投屏输入代码、测试画布及模拟 OCR/控制连接验证：打开面板可操控，主动取色完成后自动退出检查模式，128 次连续 OCR 请求使用同一选区，期间可发送点击、拖动、键盘与滚轮控制消息。

以上不代替真实设备、真实全局快捷键按键和 Windows/Linux 原生验收；远端 CI 与发布产物仍须在标签推送后核对。

正式版本及前端、桌面、Python SDK 版本统一为 `v1.25.2`。推送标签后由仓库 GitHub Actions 构建与发布；标签推送不代表多平台构建、安装包或 SDK 已发布完成。
