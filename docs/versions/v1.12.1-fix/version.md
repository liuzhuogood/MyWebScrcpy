# v1.12.1-fix 版本说明

更新日期：2026-10-10。

## 发布内容

- 设置增加“唤醒后尝试解锁”，默认关闭，使用 ADB 唤醒屏幕并请求解除锁屏。
- 开启设置后，进入已亮屏设备、设备从灭屏变为亮屏、重新开启设置时均可尝试解锁；每次亮屏仅尝试一次，避免重复请求影响操作。
- 请求增加超时、取消和并发保护，离开播放器或关闭设置时取消进行中的自动解锁。
- 收录 v1.12.0 标签之后已提交的云与手机图标、侧栏关闭入口、分割线与图标统一、模板资产管理收口，以及拖动结束时重复触控反馈的修复。

## 验证与边界

- 自动解锁回归测试 17 项及前端类型检查、生产构建已通过。
- 设备 10.0.0.244:5555 的 ADB 锁屏状态确认已解锁；低帧率视频可能仍显示解锁前的旧画面。
- ADB 请求不能代替密码验证；有密码的设备仍需手动验证。
- 正式版本来源 VERSION、前端包版本与 OpenAPI 版本统一为 1.12.1；标签使用 v1.12.1，保留已发布的 v1.12.0。
- 发布构建及 GitHub Release 的完成状态以本次标签触发的工作流结果为准。
