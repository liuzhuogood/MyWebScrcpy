# v1.26.0：HID 硬件模拟通道、点击注入模式与 Python 环境平滑切换

## 核心变更

1. **HID 硬件模拟通道与点击注入模式**：
   - 系统设置支持选择点击注入模式。
   - 新增 HID 硬件模拟通道（`uhid` / `aoa`），支持在安全限制或特殊场景下通过硬件级键盘、鼠标事件模拟输入。

2. **Python 运行环境平滑切换与并发保护**：
   - 依赖管理支持在切换或更新 Python 解释器时，自动优雅停止依赖旧环境的后台进程（模板匹配服务、PaddleOCR、Indra OCR）。
   - 增加运行时互斥锁，避免旧读操作和新写操作竞争。
   - 前端依赖面板补充切换 Python 的二次确认弹窗，明确提示受影响的服务。

3. **服务配置与界面交互优化**：
   - 模板匹配服务面板样式卡片化统一，避免长流水布局。
   - 服务偏好管理器增加运行时安全停止逻辑，防止异步启动旧状态覆盖用户偏好。

4. **AI 集成与自动化技能市场规划与交互原型**：
   - 规划新增“AI 集成”及自动化技能市场，支持外部工具接入指南与技能查找。
   - 交付 v1 与 v2 可交互 Vue 原型，包含接入指南、技能市场、二级详情页、多目标助手选择及示例安装包下载。
   - 沉淀设计文档、术语字典与多端实拍截图；真实接入与执行能力规划于后续版本迭代实现。

## 本地验证

- Go 模块单元测试全量通过（包含 `dependencies`、`serviceprefs`、`ocr` 等并发与生命周期测试）。
- 前端代码及可交互原型通过 `vue-tsc` 类型检查与 Vite 生产构建。
- 版本号同步检查与换行一致性测试全量通过。

## 发布状态

正式版本及前端、桌面、Python SDK 版本统一为 `v1.26.0`。推送标签后由仓库 GitHub Actions 自动触发多平台 CLI、Windows GUI、macOS DMG 及 Docker 镜像的构建与发布。
