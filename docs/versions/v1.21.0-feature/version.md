状态：已创建设计及任务记录，待实施。创建此设计时正式 `VERSION` 为 `v1.20.0`；本设计未实施、未部署。

5. 第一阶段拟覆盖基础动作；模板匹配作为后续评估，不把占位方法或模板资产管理计为真实匹配能力。
