## 实现约束

- 发现服务最多同时一个扫描任务和一个扫码会话，命令有超时，扫描 8 路并发。扫描最多 256 个局域网 IPv4、每个最多 8 个端口；持续扫描默认 UI 间隔 30 秒，可选 10–3600 秒，任务最多 30 分钟。
- 浏览器轮询维持任务租约，关闭对话框主动取消；15 秒无轮询自动取消，服务退出取消并等待任务。TCP 开放不代表 ADB 可用，在线确认后才持久化。
- 扫码按 [Android ADB Wi-Fi 官方机制](https://android.googlesource.com/platform/packages/modules/adb/+/HEAD/docs/dev/adb_wifi.md) 实现，不把配对端口当连接端口，口令不写日志。
- 本地音量与设备音量分开；打开投屏的唤醒动作独立于电源键偏好，原电源键行为保留。
- 根 `AGENTS.md` 已写入一句简洁 UI 规则；未替换应用 Logo。
