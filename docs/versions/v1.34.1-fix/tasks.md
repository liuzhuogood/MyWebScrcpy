# v1.34.1-fix 实施与验证清单

状态：2026-11-05 已获统一实施、合主干和发布授权；共 9 项。完成勾选表示代码与所列定向检查完成，不代表全部设备/平台人工验收。

## BUG-001：无阻挡浮层与外部点击收起

- [x] 移除全屏遮罩，保留卡片及胶囊自身交互；用 VueUse `onClickOutside` 监听外部点击，不阻止事件传播。
- 最终期望以用户最新确认为准：点击卡片外收起卡片，同时同一次点击正常到达投屏/背景，不需要第二次点击；卡片内点击不误关，胶囊切换与展开编号区域保持一致。
- 已确认源码：外层 `pointer-events-none`、卡片/胶囊 `pointer-events-auto`，没有透明全屏命中层。

## BUG-002：Android 无线调试扫码配对与连接

- [x] 电脑二维码、手机无线调试扫码，精确匹配 mDNS 服务后通过 ADB TLS 配对，确认连接在线后入库。
- 成熟库：`qrcode` 生成二维码，调用既有受管理 ADB，不自造配对协议。扫码会话 2 分钟超时，可取消，口令仅供配对且不写日志。
- 已验：二维码显示、取消；假 ADB 验证服务名匹配、stdin 口令、配对失败不报告连接成功。尚未用手机完成整套扫码配对。

## BUG-003：IP 段、端口和常态扫描

- [x] 支持完整起止 IP、`192.168.1.100到200` 等末段缩写，以及一个或多个端口；提供持续扫描开关、间隔和停止操作。
- 使用受控任务，8 路并发，TCP 探测 350ms，单 ADB 命令 5 秒超时；最多 256 地址、8 端口，拒绝公网范围。持续扫描间隔 10–3600 秒，UI 初值 30 秒；单任务上限 30 分钟。
- 只有确认 ADB `get-state=device` 才保存设备；关闭对话框取消，15 秒失去轮询租约停止，退出服务收尾。
- 已验：边界/重复端口/中文范围/取消/容量/关闭/连接失败测试，以及浏览器单回环地址扫描。未进行大范围真机扫描。
