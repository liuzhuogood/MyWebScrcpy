# v1.5.4-feature 版本摘要

1. XML 属性详情支持将任意非空属性（如 `class`、`package`、`content-desc`）组合进 XPath，默认仍优先使用非空 `resource-id` 或 `text`。
2. 选择 XML 节点或切换属性复选框后，自动测试生成的 XPath，并更新匹配数量与投屏绿框。
3. 移除属性详情中与 XPath 输入框重复的文本，检查器说明同步更新。
4. 播放器工具栏新增浏览器画中画入口，将当前投屏画面显示在独立浮窗中；兼容标准视频画中画、Safari 视频画中画和文档画中画能力。
5. 检查器取色读数同时展示像素坐标与 0～1 的归一化坐标，并将“检查”按钮图标调整为清晰的放大镜样式。
