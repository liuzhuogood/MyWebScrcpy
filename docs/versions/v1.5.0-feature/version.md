# v1.5.0-feature 版本摘要

1. 新增基于共享 H.264 会话的受控 MP4 录屏：启动、查询、停止和下载均绑定设备 serial，单设备互斥，启动时必须指定 1 分钟至 8 小时自动停止时长。
2. 使用 Go MP4 封装库保留 scrcpy 时间戳与最后画面时长；临时文件仅在封装成功后原子发布，服务重启清理未完成文件，完成文件受目录配额与保留期控制。
3. 播放器提供默认 30 分钟、可键盘操作的时长滑块，以及直接可见的录制/停止/下载状态；工具栏按真实可用宽度收纳低优先级按钮。
4. 新增受控原始 ADB 命令接口：固定 serial、参数数组执行、默认 60 秒/可配置上限、输出截断、FIFO 异步状态查询及显式受限 `parallel`；不开放宿主机 shell 或 host/target 参数。
5. 新增 `/api/sendkey` 组合键接口，并让 Vision key 动作透传 Android `meta_state`；仅允许 Ctrl、Alt、Shift、Meta，拒绝非法或重复修饰键。
6. 已通过单元测试、静态检查、浏览器宽窄屏检查及 `10.0.0.30:5555` 的实机录屏下载、MP4 播放和安全 ADB 命令验证。
7. 播放器新增可移动、可缩放的区域截图选框，可将当前 Canvas 画面按所选区域直接下载为 PNG；原始尺寸入口改为在当前页打开。
8. 录制弹出层新增录制记录：显示开始时间和实际录制时长，可下载或删除已结束录像；新增记录查询、删除和“未传记录 ID 时下载最近完成录像”的接口。
