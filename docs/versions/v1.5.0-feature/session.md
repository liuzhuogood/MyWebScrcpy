# v1.5.0-feature 会话记录

## 2026-09-09

**用户**：为 OpenCV 自动化服务规划了录屏启动、停止、下载能力，并询问是否应由 MyWebScrcpy 承担。

**代理**：已核对 MyWebScrcpy 的共享 scrcpy 会话、Vision 视频流、ActionQueue 和文件下载能力。建议录屏的实际实现和录像文件管理归 MyWebScrcpy：它更接近原始视频流，可避免 OpenCV 服务重复订阅、解码和重编码；OpenCV 仅在需要统一自动化入口时转发请求。

**用户**：确认在 MyWebScrcpy 项目增加该版本；播放器 UI 要增加录制功能，且工具栏按钮不能默认全部收进“更多”，只在响应式布局空间不足时才收起。

**代理**：本轮创建 `v1.5.0-feature` 设计记录，不修改 Go、HTML、CSS 或 JavaScript。版本号以已发布的 `v1.4.2` 为基线，按新增功能递增 minor。播放器将采用基于实际可用宽度的溢出策略：常用按钮和录制按钮默认直接可见，仅将低优先级按钮在工具栏确实放不下时移动到“更多”菜单。

**用户**：录制启动应增加防忘记参数——录制超时时间；播放器可拖动选择，最长 8 小时。

**代理**：录制时长改为启动请求的必填字段，最大值固定为 8 小时，服务端到时自动停止并完成文件封装。播放器在启动前提供可拖动的时长选择控件；设计建议默认 30 分钟，实施前可按用户确认调整。

**用户**：询问 Sendkey 是否可设计支持组合键，并要求开放任意 shell，最好直接开放执行 ADB 命令接口以覆盖通用自动化能力。

**代理**：组合键可采用“主 keycode + Ctrl/Alt/Shift/Meta 修饰键集合”，由 MyWebScrcpy 补齐 Vision 动作链路的 Android meta state 透传。原始命令能力设计为受控的任意 ADB 参数接口：服务固定使用已选 `serial` 构造 `adb -s <serial> <args...>`，不执行宿主机 shell、不接受 `adb` 二进制或主机连接参数；参数数组可覆盖 ADB 的 shell 和其他子命令。每条命令必须有上限超时、输出截断和 per-serial 命令闸门，避免注入、无限输出、跨设备及与 scrcpy 控制并发冲突。

**用户**：60 秒应作为 ADB 命令超时的默认值，但调用方可以通过参数自定义。

**代理**：`timeout_ms` 调整为可选字段，默认 60000 毫秒；服务端仍以部署配置的最大允许超时作最终限制，拒绝或裁剪超过该上限的请求，确保自定义时长不会留下无限运行子进程。

**用户**：要求推进 `v1.5.0-feature` 的开发并进行测试。

**代理**：已开始实施前核对。仓库当前已存在该版本的四件套和未提交的播放器区域截图改动（`web/player.html`、`web/css/style.css`）；后者不属于本版本设计范围，实施时将保持不动。录屏的默认时长、全局磁盘配额、保留期，以及入口是否限于播放器页仍待确认；这些参数会影响实际服务行为，确认后再开始代码实现与测试。

**用户**：询问同一时间只能执行一个 ADB 命令时，是否不能调用两次执行两个命令。

**代理**：同一 serial 可以连续提交多条命令，第二条进入 FIFO 队列而非被拒绝；不同 serial 可并行。新增异步提交与命令状态查询设计，避免排队命令占用 HTTP 连接。同一设备的任意命令真并行仍默认不开放，以避免 ADB shell、安装、点击与 scrcpy 控制竞态。

**用户**：要求增加显式 `parallel` 模式，不要将同一设备命令限制得过死。

**代理**：增加 `parallel: true`。默认仍进入同 serial FIFO 队列；显式并行请求绕过 CommandGate，可与同设备 ADB 命令及 scrcpy 控制同时运行。并行模式保留每条命令的超时、输出截断、子进程回收和可配置的资源并发上限，不隐藏其设备状态竞态风险。

**代理**：采用可配置的保守录像默认值：播放器页入口、时长默认 30 分钟、录像目录 `recordings`、总配额 10 GiB、完成录像保留 7 天。录屏以 Go MP4 封装库复用共享 H.264 帧和时间戳，不重新编码；保留已有区域截图改动。

**代理**：已完成录屏、响应式工具栏、受控 ADB 命令和组合键实现。Go 单测、静态检查和浏览器宽窄屏检查通过；`10.0.0.30:5555` 实录、停止、下载的 MP4 经 `ffprobe` 验证可播放且约 5 秒，ADB `shell echo` 真实调用返回成功，目标/host 参数与重复修饰键均被拒绝。

**代理**：版本实现已以 `dbe0a7b` 提交并推送至 `origin/main`；提交严格排除了工作区中既有的区域截图改动。

**用户**：要求部署到 `10.0.0.6`，随后提交推送并打 tag。

**代理**：已将当前 Linux amd64 构建部署到 `/opt/mywebscrcpy`，远端 systemd 为 active，HTTPS 首页返回 200，二进制 SHA-256 与本地构建一致。区域截图和同页原始尺寸入口将与正式 `v1.5.0` 元数据一并提交、推送和打标签；运行时录制文件不纳入版本库。

**用户**：要求在开始录制弹出层增加可删除的录制记录，显示录制时间和录制总时长；并增加记录查询接口，下载接口可传记录 ID，不传时下载最后一次录制的视频。

**代理**：录制弹出层新增记录列表，显示开始时间和实际时长，并支持下载或删除已结束记录。新增 `GET /api/recordings`、`DELETE /api/recordings/{recording_id}` 和 `GET /api/recordings/download`；后者可选 `recording_id`，省略时只选择该设备最近一次完成的录像。既有带路径 ID 下载接口保留。
