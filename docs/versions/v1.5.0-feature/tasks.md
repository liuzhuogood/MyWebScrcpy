# v1.5.0-feature 任务清单

## 版本记录

- ✅ 创建版本四件套，记录录屏归属、HTTP 生命周期和响应式播放器要求。
- ✅ 已记录本次开发、测试授权、实现决策和真实设备验证证据。

## 设计确认

- ✅ 固定录制自动停止上限为 8 小时；启动请求必须传 `max_duration_ms`。
- ✅ 采用默认 30 分钟、总配额 10 GiB、完成录像保留 7 天；均可通过环境变量调整，直接封装 H.264。
- ✅ 本期入口只放播放器页，不覆盖 dashboard。
- ✅ OpenCV 不镜像或转发录屏接口，调用方直接使用 MyWebScrcpy。

## 实现

- ✅ 新增独立 RecordingManager、受控录像目录和共享会话只读有界订阅；从配置帧/关键帧开始，不阻塞读帧循环。
- ✅ 实现 H.264 MP4 封装、原子发布、1 分钟～8 小时自动停止、单设备互斥、状态机和自动清理。
- ✅ 实现录屏启动、状态、停止、下载 API 与明确 JSON 错误响应。
- ✅ 实现录制记录查询、已结束记录删除，以及可省略记录 ID 的最近完成录像下载。
- ✅ 新增 per-serial CommandGate；默认 ADB 命令和 scrcpy ActionQueue 共用串行闸门。
- ✅ 实现 `POST /api/adb/commands`：默认 60 秒、可配置上限、固定 serial、参数数组执行、目标/host 参数过滤和输出截断。
- ✅ 实现 FIFO、`async: true`、命令状态查询及可配置的排队超时；不同 serial 可并行。
- ✅ 实现 `parallel: true` 与 `ADB_MAX_PARALLEL_PER_SERIAL` 上限。
- ✅ Vision Message、Action Request 与执行器透传 key `meta_state`，兼容无修饰键请求。
- ✅ 提供 `/api/sendkey` 的 `shift`、`alt`、`ctrl`、`meta` 受限映射与重复/非法修饰键校验。
- ✅ 在播放器增加录制、停止、录制状态、下载入口和可拖动的 1 分钟～8 小时自动停止时长选择。
- ✅ 将工具栏改为实际宽度驱动的优先级溢出；录制、全屏和区域截图直接可见。
- ✅ 实现播放器 Canvas 区域选择、移动/缩放与 PNG 下载；原始尺寸入口在当前页打开。
- ✅ 更新中英文 README 的录屏接口、环境变量和文件生命周期说明。
