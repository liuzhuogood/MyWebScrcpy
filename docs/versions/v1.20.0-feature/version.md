# v1.20.0：桌面客户端与安全更新

1. 新增 Tauri 原生窗口、菜单、系统托盘，支持单实例、窗口恢复及 GUI/服务启动模式。
2. 桌面后台使用回环随机端口、私有控制令牌及独立用户数据目录，退出时清理自有进程和投屏会话。
3. 新增 ADB/Python 依赖检测、官方安装入口与路径配置；客户端链接由系统浏览器打开。
4. 桌面支持完整签名更新包；独立服务支持资源校验、维护保护、数据库备份与失败回滚。Docker/systemd 使用对应部署流程更新。
5. 发布流程构建多平台独立服务和桌面安装包，并生成桌面更新清单。
6. 脚本助手支持 Markdown 回复与侧栏宽度调整；优化移动端导航和播放器工具菜单。

macOS 完整 App 更新包含新版启动检查与失败回滚；Windows/Linux 新版启动失败自动回滚尚未接入原生安装器。完整发布包的真实升级及各平台原生安装仍需环境验收。macOS 当前使用 ad-hoc 签名，尚未配置正式 Apple 签名与公证。
