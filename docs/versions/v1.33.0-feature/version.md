# v1.33.0-feature 版本摘要

## 状态
- 阶段：已完成代码实施与全栈门禁验证，主干代码合入收口完成
- 分支：`main`
- 正式版本号：维持 `v1.29.0`（原型归档不改变正式发布版本）

## 阶段成果

### 1. 首页右侧“操作”面板重构与全局控盘
- **更名与定位升级**：原右侧“批量操作面板”正式更名为**“操作”**面板，提升为首页全局统一控制中枢。
- **两态平滑折叠**：
  - **展开态 (Expanded，宽约 320px)**：收纳设备搜索、视图模式、连续滑动调节组、编号显隐网格（01..N）与四键纯图标动作组；
  - **收起态 (Collapsed，宽 52px 极窄侧边条)**：停靠右侧，包含展开把手按钮（`<PanelRightOpen>`）、快捷搜索展开、快速刷新、视图直切与已选设备 Badge，文字纵向竖排“操 作”。
- **界面彻底减负与视觉纯净化**：
  - 去除搜索框上方的“设备控制”冗余标题，搜索框紧凑置顶；
  - 去除面板底部的“执行反馈”历史日志长列表，批量点击通过即时轻量 Toast 反馈，消除冗余滚动条；
  - 顶栏数量胶囊迁移至“设备显隐”旁（如 `5/6` 在线），顶栏标题保持极简“操作”并集成全屏切换按钮。
- **批量动作纯图标化与新增“同步操作”**：
  - 动作按钮彻底去除中文文本，改为纯图标展示，鼠标 Hover 悬停展示功能说明；
  - 新增**“同步操作”**：通过操控一台手机，将其所有触控与按键实时同步至全部已勾选设备。

### 2. 去除顶部大横条与筛选提示，实现卡片顶格
- 彻底移除原 `HomeControlCapsule` 大横条，大幅释放首屏垂直可用空间。
- 彻底移除设备展示区上方的“当前筛选显示 X / Y 台设备 · 清空筛选条件”提示条，避免与右侧面板冗余。
- 左侧设备卡片从容器最顶端 **0 间隙直接顶格排布**，视野纯粹开阔。

### 3. 去除死板过滤，升级为三大连续滑动调节
- 彻底剔除低频且僵硬的“全部、直连、无线、离线”分类胶囊与离散开关。
- **剔除“紧凑阵列 (`compact`)”**，视图模式精简为“卡片视图 (`deck`)”与“手机视图 (`phone`)”。
- **新增三大连续滑动调节条 (Sliders)**：
  1. **手机大小 (Scale)**：70% ~ 140%（对应卡片基准宽 190px ~ 380px，默认 270px 100%），左侧网格实时无级放大缩小并自动流式换行；
  2. **投屏码率 (Bitrate)**：2 Mbps ~ 16 Mbps（流畅 2M / 标清 4M / 超清 8M / 极致 16M）；
  3. **投屏质量 (Quality)**：50% ~ 100%（720P / 1080P / 2K超清 / 100%原画）。
