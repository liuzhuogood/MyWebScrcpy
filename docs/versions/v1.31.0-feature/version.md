# v1.31.0-feature 版本说明

## 1. 新增与调整

1. **设备列表首页视觉全新升级（Holo Spatial Deck）**：
   - 采纳“全息空间甲板”高科技视觉设计重构首页；
   - 采用深度磨砂玻璃拟态（Glassmorphism）、深邃渐变极光背景（HomeAuroraBackground）与 3D 空间倾角悬浮交互（3D Perspective Tilt）；
   - 顶部引入居中悬浮控制胶囊（HomeControlCapsule），集成实时搜索、极速通道切换（全部/直连/无线）与视图模式切换（卡片甲板/紧凑阵列）；
   - 纯蓝 `#406BDB` 投屏主按钮与场景化“前台应用”感知微卡片；
   - 全局隐藏帧率，文案统一定位为“设备列表”并移除动态装饰，满屏全宽自适应展开；
   - 统一入口文案为“大屏监控”（对齐 `docs/glossary.md`）。
2. **桌面端无级全透明穿透与双主题原生融合**：
   - 架构收敛为 Tauri 原生 `transparent(true)` + Web 层受控无级透明，支持 0%~100% 窗口透明度调节，彻底解决 0% 透明度下原生灰色背景残留问题；
   - 完善深空（`#060810`）与澄澈（`slate-100/90`）双主题定义，彻底阻断 macOS 系统浅色外观向黑暗模式透光泛白的问题。
3. **macOS 原生沉浸式窗口与红绿灯避让**：
   - 桌面端配置 Tauri `TitleBarStyle::Overlay` 与 `hidden_title(true)`，取消原有灰色窗口边框与顶栏占用；
   - 顶栏高度收缩至 macOS 标准紧凑高度（`h-11` 44px），图标及标题右移（`pl-[82px]`）避让原生红绿灯，并支持原生拖拽移动窗口。
4. **小窗（画中画）交互闭环与卡片按钮简化**：
   - 无边框小窗左侧新增 `<X>` 关闭按钮，直接关闭原生窗口/浮窗；
   - 设备卡片移除独立的“恢复”按钮，由原画中画按钮兼任恢复动作，状态清晰不冗余。
5. **投屏详情页（DevicePlayer）视觉同步进化**：
   - 投屏详情页面全面适配全息空间甲板（Holo Spatial Deck）规范；
   - 注入深邃极光渐变与矩阵星网背景，投屏画面呈现大圆角悬浮巨幕阴影（`shadow-[0_20px_50px_rgba(0,0,0,0.35)]`）；
   - 顶栏与控制按钮升级为微晶体玻璃胶囊，并自适应 macOS 紧凑顶栏与红绿灯避让。
6. **顶栏架构公共组件化（AppHeader）与多页面深度复用**：
   - 将 `AppHeader.vue` 封装为通用全局顶栏组件，首页、大屏监控（`DashboardView`）、投屏详情页（`DevicePlayer`）全面复用；
   - 统一呈现全息微晶磨砂玻璃视觉基调，并统一处理 macOS 桌面端红绿灯避让及无边框悬停唤出；
   - 桌面端主窗口配置 macOS 原生红绿灯上下精准居中（`traffic_light_position(18.0, 15.0)`）；
   - 顶栏拖拽区域增加原生窗口双击最大化切换（`toggleMaximize`）响应，同时自动排除交互控件的点击冒泡。

## 2. 交互与功能保留

- 完整保留既有设备列表的全部业务能力：ADB 自动轮询、别名就地编辑、设备重连与删除、快捷打开 Scrcpy 投屏、调起原生小窗画中画、添加网络设备、系统配置入口等。
- 确保在 Web 浏览器与桌面 GUI 客户端两端均可完美自适应显示。

## 3. 验证与交付

- 前端构建验证：`pnpm --dir frontend run build` 编译通过。
- 桌面端编译验证：`DESKTOP_BUNDLES=app node scripts/build-desktop.mjs` 编译 GUI 应用程序通过。
- 运行验证：启动 GUI 应用程序并验证 0% 全透明穿透、双主题显示及各项设备控制操作。
