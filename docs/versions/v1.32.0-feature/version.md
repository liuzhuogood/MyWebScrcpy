# v1.32.0-feature 版本规划与实施进度

状态：已完成代码实施与前端/后端单元自测及生产构建；原型经主管真实浏览器验证通过；真机与最终交互由主管亲自验收中。正式 `VERSION` 保持 `v1.29.0`。

1. **首页手机视图**：已在现有甲板（deck）和紧凑（compact）视图之外正式增加实时手机视图（phone），整合全屏、显隐控制、尺寸切换（小/中/大/铺满）和单机控制；已移除 Web 桌面导航、移动菜单与桌面原生菜单中的独立大屏入口，旧 `/dashboard` 路由原样保留。取消旧每页台数与分页，全面由右侧批量面板的真实设备编号小方块选择器驱动显隐。
2. **右侧预留批量操作面板与组件化**：已重构为位于设备卡片主展示区右侧的预留面板（不遮挡卡片，窄屏自然流式堆叠，无幽灵 modal 遮罩，关闭后入口可恢复），顶部搜索与筛选控制栏保持整行不被挤压；面板全面组件化拆分为面板壳（`BatchPanelShell`）、编号显隐选择区（`BatchDeviceGrid`）、批量勾选范围（`BatchTargetScope`）、离散按键动作（`BatchActionButtons`）、显示设置（`BatchDisplaySettings`）、逐台结果（`BatchResultList`）。
3. **编号小方块显隐体系**：面板内按 serial 字典序稳定映射编号（01..N，真实设备不伪造 60 台），点选编号切换单台显隐，支持“全显”与“只显已选”；隐藏卡片不丢失编号按钮，显隐不与批选递归清空；有界并发批操作仅对显式勾选的在线真实设备生效。
4. **原型演进**：保留历史方案 `home-phone-batch-v1`，新增独立交互原型 `home-phone-batch-v2`。
4. **后续路线图**：v1.33 安排标签分组与实时群控，v1.34 安排短语/文件/APK 分发，v1.35 安排动作录制与条件回放；后续版本保持未启动。
5. **验证边界**：下级实施 Agent 已完成单元测试、生产打包构建、类型检查与后端接口验证；主管已完成原型浏览器实测；真实真机回归验收由主管亲自执行。

详细对照、设计和验收标准见 [design.md](design.md)，进度见 [tasks.md](tasks.md)。
