# v1.32.0-feature 版本规划

状态：仅完成规划记录，功能待实施。正式 `VERSION` 仍为 `v1.29.0`。

1. **首页手机视图**：计划在现有两种首页视图之外增加实时手机视图，将现有大屏监控能力整合到首页，移除 Web、移动与桌面原生菜单中的独立大屏入口。
2. **右侧批量操作面板**：计划提供本页设备多选、统一返回/主页/最近任务及逐台结果；显示设置为面板的一部分，不能替代批量操作。
3. **显示数量与资源边界**：计划支持每页台数、分页、显隐、尺寸、铺满和全屏，区分显示数与选中数，仅为当前页真实在线设备订阅视频。
4. **后续路线图**：v1.33 建议安排标签与实时群控，v1.34 安排短语/文件/APK 分发，v1.35 安排动作录制与条件回放；通知、授权分享和非 ADB 接入先做验证。后续版本号为建议排期，不代表已立项实施。
5. **验证边界**：本轮完成竞品/源码对照和任务拆分，没有业务实现、原型交互、真机、容量或部署验收；旧 `/dashboard` 地址处置仍需明确。

详细对照、设计和验收标准见 [design.md](design.md)，进度见 [tasks.md](tasks.md)。
