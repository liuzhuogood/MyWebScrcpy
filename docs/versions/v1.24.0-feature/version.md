# v1.24.0-feature 版本说明：GUI 小窗透明度与鼠标穿透（待实施）

1. **小窗透明度调节**：
   - 桌面投屏独立小窗支持背景透明渲染；
   - 提供 20% ～ 100% 透明度调节，便于边查看手机屏幕边参考底层桌面内容。
2. **小窗鼠标点击穿透**：
   - 支持开启鼠标穿透，点击小窗区域直接穿透至底层桌面或第三方应用程序；
   - 包含配套的防死锁退出机制：全局系统快捷键（如 `Alt + P` / `Option + P`）一键恢复，并在主窗口设备卡片提供解除操作。
3. **验证与注意事项**：
   - 当前版本已完成架构与技术可行性评估、防死锁时序设计、四件套版本记录建立与分支基线创建；
   - 本次仅建立版本规划与设计，未实施业务代码；正式实施前需重点确认快捷键方案。
