# v2026.11.5-1 版本说明

## 新增

- 首页采用 iOS 悬浮底栏，整合设备选择、显示设置、批量操作与群控；设备卡片可打开网页浮动投屏或桌面原生小窗。
- 添加设备支持 Android 无线调试扫码配对，以及局域网 IPv4 范围、单个/多个端口扫描和可停止的持续扫描。
- 编号区域支持紧凑展开；桌面视口可直接展示 500 台编号，支持滚动后框选和模拟选择预览。
- 新增项目发布工作流：当前版本说明优先、缺失时根据真实发布基线与提交生成；Release 正文、版本与目标提交由 CI 校验。

## 修复

- 浮层不再用遮罩拦截背景；点击卡片外会收起卡片，并让同一次点击继续到达背景目标。
- 添加设备对话框删除多余说明，“保存”按钮使用标准蓝色且无图标。
- 投屏小窗与详情页提供本地音量调节和静音；不改变设备系统音量。
- 投屏打开时主动唤醒并请求解除普通锁屏，核对真实电源和锁屏状态；未知或安全锁屏不声称解锁成功。
- 桌面开发快捷操作可在源码变化后重启本工作区拥有的旧实例，构建并显示当前源码应用，保留网页操作。
- 修正编号矩阵滚动偏移与 Mock 选择门控：模拟数据可选择预览，但不能派发真实设备命令。

## 验证

- Go 全量测试、设备发现与屏幕状态定向竞态测试通过；Windows 设备包测试二进制交叉编译通过。
- 前端类型检查、构建，以及音量、唤醒、选择门控定向测试通过。
- 浏览器验证添加设备必填校验、单回环地址扫描、二维码生成/取消、编号 500 的滚动框选；1523×957 视口展开可见 500/500 编号。
- 一台真实设备从熄屏锁定变为亮屏未锁定并输出投屏帧；当前源码桌面应用的原生首页已截图确认。
- 版本同步与发布说明来源/回退测试通过。

## 已知限制与范围

- 手机实际扫码配对、不同厂商/安全锁屏、真实听感及全部原生 WebView 音频能力仍需人工验收，不以模拟测试冒充完成。
- Codex 自身快捷菜单受工具访问限制；已验证配置对应命令和原生窗口，菜单实际点击需人工确认。
- 持续扫描依赖对话框轮询租约，关闭或断开后停止，不是在后台永久扫描；最长 30 分钟，可主动重启任务。
- 统一采集与当前运行应用图标缓存是独立 `v1.35.0-feature` 的设计文档，本版没有实施；未替换应用 Logo。
- macOS 本地包使用 ad-hoc 签名，正式公证不由本机构建代表。远端构建、Release 资产及 Docker/SDK 状态以对应 Actions 终态为准。
