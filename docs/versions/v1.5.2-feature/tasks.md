# v1.5.2-feature 任务清单

## 版本记录

- ✅ 创建版本四件套，记录坐标取色、XML 树和 XPath 交互设计。
- ✅ 只读参考 10.0.0.11 的 adb-uiweb XML dump 与树联动实现。

## 后端

- ✅ 实现受控 `GET /api/ui/xml?serial=...`，复用在线 serial 校验和 per-serial dump 互斥。
- ✅ 校验 XML 单根、大小限制、设备错误和结构化响应。
- ✅ 为 dump 成功、设备不可用边界、并发和无效 XML 添加单元测试。

## 播放器检查浮层

- ✅ 检查模式改为投屏与检查面板左右分栏；投屏靠左，检查宽度可拖拽调整，并适配窄屏堆叠。
- ✅ 实现 rAF 合并的鼠标坐标换算、RGB/HEX 取样、13 × 13 像素放大镜和十字线；首次点击冻结读数与十字线，再次点击恢复跟随。
- ✅ 新增独立 XML 检查叠层，不与 Vision 检测 overlay 共享状态。

## XML 与 XPath

- ✅ 解析 XML 快照，默认展开树；树节点属性详情与 XPath 使用安全的轻量语法着色。
- ✅ 实现树节点绿框的双向单选与再次点击取消选择；命中绿框时拦截设备触控事件。
- ✅ 实现 XPath 输入、匹配数量、异常提示、所有命中 bounds 的高亮和清除。
- ✅ 支持显示当前 XML 快照全部带 bounds 的元素，并从绿框反选 XML 树节点。
- ✅ 按 XML 原始尺寸与 Canvas 实际尺寸做 X/Y 坐标换算，解决缩放投屏时绿框偏移。
- ✅ XML 接口返回 Android 有效显示尺寸，避免将系统栏裁剪后的 XML bounds 高度拉伸至完整视频画面。
- ✅ 元素详情支持勾选任意非空属性（含 `text`、`resource-id`、`class`、`package`、`bounds`）组合 XPath；默认优先稳定的非空 `resource-id`。
- ✅ 选择 XML 节点或切换定位属性时自动执行生成的 XPath，并移除属性详情中的重复 XPath 文本。

## 验证与发布

- ✅ 通过坐标换算、独立叠层同步和窗口/全屏变更处理覆盖原始尺寸、显示尺寸与全屏映射；旋转后的真实设备回归留待后续设备测试。
- ◐ 已在 `10.0.0.6` 的真实设备验证 XML 快照、可展开树和检查浮层；空/不完整 XML、XPath 多命中和旋转仍待专项回归。
- ✅ 已更新正式版本为 `v1.5.2`，提交、推送并部署到 `10.0.0.6`。
- ✅ 本轮检查器修复已隔离构建并部署到 `10.0.0.6`；真实投屏页的 XML 检查器截图已补入 README（待与本轮源码一并提交）。
