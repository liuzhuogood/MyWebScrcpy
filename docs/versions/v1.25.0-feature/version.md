# v1.25.0-feature：小窗透明度、外部任务运行与依赖清理

状态：等待 Actions 发布。已合并 v1.24.0 小窗视觉增强与 v1.25.0 任务架构重构，并完成冗余模块与遗留变量清理；未提交的 OCR/服务配置新改动不属于本版本发布范围。

### 核心变更
1. **小窗透明度与鼠标穿透 (v1.24)**：GUI 小窗支持 0%～100% 透明度调节与鼠标穿透，支持快捷键（Option/Alt + P 或 Control + Option/Alt + P）、主窗口与托盘一键恢复。
2. **任务架构重构 (v1.25)**：全面拥抱外部自动化。彻底移除内置 Pi 运行环境、模型配置、AI 助手、内置脚本编辑生成、Cron 调度及托管执行。
3. **任务运行面板与上报 API**：新增 `/tasks` 面板用于集中查看外部上报的任务状态、实时日志和运行结果，提供轻量 Python `TaskReporter` 上报工具。
4. **数据库与依赖精简**：任务系统数据库重置为外部任务上报结构，依赖管理精简为仅保留系统/内置 ADB 与 Python 配置。
5. **遗留代码与孤立文件清理**：清理历史残余的 `internal/pythoncheck` AST 校验包、孤立组件 `DevicePlayerDialog.vue`、`StubView.vue`、未引用的 UI 分隔条以及录制模块残留的 `ownerTaskID`、`startOwned` 等旧字段与死逻辑。

### 验收与未验证边界说明
- 自动化单测、前端编译打包、Go 静态检查与隔离源码测试已全量通过。
- 复杂环境下的桌面原生按键穿透手感与真机多任务长时间运行表现以实际运行环境为准，不作为本版本已人工穷尽验证的声明。
- 工作区当前正在开发的 OCR 管理与服务配置新特性明确不包含在本次发布提交中。
