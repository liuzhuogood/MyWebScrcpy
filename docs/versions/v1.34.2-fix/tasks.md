# v1.34.2-fix 实施与验证清单

状态：本轮 5 项代码已实现，以下区分开发完成与仍需人工的原生验收。源码按用户授权提交推送，未发布。

## BUG-001：GUI 首页设备卡片拖动框选无反应

- [x] 修正所有首页卡片模式的事件入口；实时画面改为明确的预览消费模式，左键拖动由卡片层框选。
- [x] 拖动超过阈值后显示蓝色选框，限定查询本卡片容器，更新已选状态；mouseup 后抑制合成 click，卸载清理监听和定时器。
- 已验：浏览器在大列表滚动后真实拖动出现蓝框，已选 1 台；选择门控、网格及群控定向测试通过。
- 待验：原生 GUI 中完整观察蓝框过程与选中反馈。原生截图受系统缩略图影响，本轮未取得完整验证，不将浏览器编号矩阵旧测试当作替代证据。

## BUG-002：GUI 点击设备卡片没有原生小窗

- [x] 整卡单击开窗，移除嵌套重复 click；标题/勾选按钮仍阻止多余冒泡，拖选后不误开窗。
- [x] 桌面调用失败时记录序列号与错误并提示，不再把失败静默降级为另一种窗口；Mock 不触发真实投屏。
- 已验：真实 GUI 点击设备卡片后前台窗口切为“vivo”独立窗口；日志确认对应投屏连接就绪。
- 待验：小窗实际画面及完整原生视觉。工具截得的是白色系统缩略图，无法据此认定画面正常或断言白屏根因；未擅自修改原生窗口创建逻辑。

## BUG-003：少量设备也出现多余滚动条

- [x] 移除视口高度和多层底部留白的重复计算，统一主页可用区域；真实超出内容交由内部滚动区处理，不裁剪设备卡片。
- 已验：1280×820 浏览器 4 台设备，内容 `scrollHeight=clientHeight=763`，页面 `scrollHeight=clientHeight=820`。真实 GUI 4 卡片加载，AX 树不再显示旧页面外层滚动条。
- 待验：不同原生窗口尺寸和用户配置的全面定量检查。

## BUG-004：设备多时固定顶部工具栏

- [x] 顶栏与滚动内容分离，底栏继续固定，主内容正常滚动并保留底部空间。
- 已验：浏览器 441 张在线 Mock 卡片，内容区滚动后顶栏 `top=0`、胶囊底部 `800`（820px 视口），外层页面未滚动。
- 待验：原生 GUI 多行/大列表实际滚动。此次未对真实设备进行批量业务操作。

## BUG-005：顶部工具栏与底部胶囊 Liquid Glass

- [x] 共用材质类，包含半透明渐层、WebKit 背景模糊、克制边缘高光/阴影、亮暗主题及减少透明度偏好。
- [x] 样式只作用于首页顶栏与胶囊，其他 AppHeader 默认样式保留；不新增说明文案、遮罩或全屏点击拦截层，保留点外部及 Esc 收起。
