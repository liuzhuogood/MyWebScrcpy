# v1.35.0-feature：统一设备信息采集与图标缓存更新

## 状态

- 2026-11-05 建立，状态为规划、未开发；本轮仅交付设计开发文档，不修改现有遥测实现。
- 承接本轮测试中另行提出的图标需求；从 `v1.34.1-fix` 的临时第 8 项意图迁入，修复版不再重复计数。
- 图标指手机设备卡片中“正在运行的应用”的图标，即当前前台应用图标，不是硬件厂商或机型图标，也不采集全部已安装应用。
- 需求与任务记录版本独立于发布日历版本，本规划不触发 `VERSION` 更新。

## 目标

温度、电量、前台应用信息及其图标获取统一交由同一个定时采集任务/调度器管理，复用采集结果；图标按用户已确认的全局包名共享，跨手机复用未过期缓存，同包并发只拉取一次，并有明确过期和更新机制；温度、电量、当前应用状态仍按设备缓存。统一调度允许不同数据有不同采集频率，不为每类数据另起独立定时器。
