# v1.19.5-feature 版本摘要

状态：正式功能已实现，完成本机构建、自动化及浏览器验证；正式版本更新为 v1.20.1，发布包另行验收。

1. 首页顶端增加系统配置弹窗，“主题”和“依赖”两个页签；依赖安装、来源选择和路径配置合并在同一卡片。
2. scrcpy-server.jar 继续随主程序内置，与客户端协议版本同步。
3. Pi 及其搜索工具从主程序/桌面安装包拆出，改为独立按需安装；ADB 新增应用目录安装方式。
4. Pi 与 ADB 支持内置/系统来源选择，系统依赖自动检测后端 PATH，缺失时填写并检查执行路径。
5. 支持系统、明亮、黑暗主题；安装成功不切换来源，缺少依赖不阻止打开首页与系统配置。
6. 增加内置 Pi/ADB 卸载，删除应用管理的依赖文件与缓存；切到系统来源后仍可清理内置副本，保留系统依赖及用户数据。

系统 Pi 只提供 pi 执行路径；后台按 PATH 查找并检查帮助、RPC 与搜索能力，不再提供 fd/rg 输入框。细节见 [design.md](design.md)，验证边界见 [verification.md](verification.md)。
