### 当前源码核对

- `main.go` 内嵌 scrcpy-server 和项目技能，启动时释放 Jar；Pi 初始化失败会退出，须在后续实施中改为功能级依赖检查。
- `internal/pibundle/bundle.go` 内嵌 `payload/*`，按内容哈希释放 Pi 包。
- `scripts/prepare-pi.py` / `scripts/pi-runtime.lock.json` 锁定 Pi 0.86.1、fd 10.3.0、ripgrep 15.2.0；`scripts/build.sh` 和桌面构建脚本均准备 Pi 包。
- 当前本机 darwin/arm64 `runtime.zip` 为 33,602,976 bytes（32.05 MiB），Jar 为 732,226 bytes（0.70 MiB）。这是资源实测，尚未构建拆包版本，不能作为最终发布包节省量。
- 当前 ADB 使用系统检测或显式路径，主程序没有内嵌 ADB；既有依赖页面管理 ADB/Python，路径写接口仅桌面控制令牌可用。Python 功能与旧入口的处置保留为后续实施前确认项。

### 正式实施与系统检测简化

**用户**：继续实现吧。

**执行**：在 `codex/v1.19.5-system-config` 实施首页系统配置、主题、应用管理安装/卸载、明确来源配置和 Pi 拆包。保留既有 Python 页面/菜单、环境变量优先级及用户旧技能/运行目录。未改正式 VERSION；未修改已有 v1.21.0-feature 文档。

**用户反馈**：搜索工具 fd 路径不需要让用户配置，只要检查 `pi --help`、`which pi` 或 `whereis pi`。

**调整**：移除正式页面的“搜索工具”明细及 fd/rg 输入框。系统来源通过 Go `exec.LookPath("pi")` 查找（相当于 PATH 中的 which），然后检查版本、帮助和无网络 RPC。搜索工具按 Pi 已确认的工具目录与 PATH 由后台查找及校验，缺失时报告具体错误，避免把仅有文件名判断为功能可用。

**验证与交付边界**：真实 macOS ARM64 Pi/ADB 安装、PATH 检测、助手/RPC、卸载重装及浏览器主题/布局验证已完成。具体命令、体积与其他平台未验收项见 [verification.md](verification.md)。源码未提交/推送，未发版。
