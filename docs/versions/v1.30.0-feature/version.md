# v1.30.0-feature 版本说明

## 1. 新增与调整

1. **投屏拖拽安装 APK**：
   - 投屏画面支持直接拖入本地 `.apk` 文件；
   - 释放时弹出安装确认对话框，展示应用包体大小与常用安装参数（`-r` 保留数据覆盖安装、`-g` 自动授予运行时权限、`-d` 允许降级安装）；
   - 执行安装并反馈进度，安装成功后支持一键快捷启动。
2. **应用管理模块**：
   - 支持扫描并展示设备内已安装的应用列表；
   - 明确区分展示**用户应用**与**系统应用**，支持分类 Tab 切换与按应用名/包名关键词搜索；
   - 提供应用运维操作集：启动、强停、清除数据、导出 APK、停用/启用及安全卸载确认；
   - 支持投屏页右侧抽屉内嵌（边看投屏边管理）与独立全屏页（`/apps?serial=...`）双重形态。

## 2. 修复与优化

1. **大批量应用查询性能优化**：
   - 采用双阶段轻量扫描，避免全量批量 dumpsys 导致的秒级接口阻塞。
2. **系统应用安全防护**：
   - 系统内置应用增加安全警示，默认推荐“停用”避免误删系统核心进程。

## 3. 验证与注意事项

1. **原型验证**：
   - 可交互原型与实拍截图位于 `prototypes/cases/app-management-v1/`，公网已完成布局与交互验证。
2. **发布说明**：
   - 本版本为重大新功能版本（v1.30.0），向后兼容既有文件管理与投屏体系。
