## 用户

1. 文档助手放到右侧。

4. 目标设备不放在 Markdown 里，在新建时指定，支持多选。
5. 模板库取得所选目标设备的模板和公共模板。

## 用户确认迁移

用户选择「明确设备迁移，auto 待配置（推荐）」。明确且没有文档冲突的单设备转为单元素列表；auto、空值或冲突记录进入待配置并暂停自动调度。原 Markdown 不在数据库迁移时静默改写。

## Codex 正式实现与验收

- 将正式工作台拆分为任务栏、编辑区、助手和弹窗；任务与新建位于左侧，底部切换源码、预览和 Python，助手位于右侧。小屏收纳为任务、文档、助手三个入口。
- API、SQLite、定时列表统一使用明确的 `target_devices` 数组；校验非空、重复、auto、公共范围与未知设备。迁移事务化且重开数据库不会重复迁移；旧单值列只留作迁移档案，不参与执行。
- Markdown 解析不再读取设备。新建示例及助手提示不生成设备字段；存量文档通过用户点击或勾选后移除旧字段。待配置任务选择设备后仍保持停用，需明确启用。
- 设备和文档保存失败保留输入，各任务保留内存草稿与会话。迟到回复不会改变其他任务；生成期间文档已修改时禁止直接覆盖。原有本地规则建议继续提供，改为显式应用。
- 模板库加载所选设备与公共模板，按准确 ID 去重；处理迟到请求、失败及搜索空态。预览使用 Marked 和 DOMPurify，显示真实模板图片、标题、列表、表格，并清理可执行 HTML。
- 手动与定时调用同一执行入口；按每台设备检查在线、占用、引用归属及模板启用状态，创建独立进程。设备参数实际传给 Python；修改任务设备只作用于后续启动。按明确执行批次关联设备结果，旧批次结束不覆盖新结果。
- 子进程组受独立超时与终止控制。编译产物在文档或标题变化时失效，保持版本号不变也会重新生成；Python 字符串转义覆盖引号、反斜杠与花括号。数据库不可用时保留原设备应用的无持久化模式，脚本相关接口明确返回不可用。
- `pnpm --dir frontend build`、`go test ./...`、`go vet ./...` 和四个受影响 Go 模块的 race 检查通过。正式浏览器验证及截图见设计文档和 verification 目录。
- 验证服务器使用隔离 SQLite、模板文件、测试设备清单及受控模型响应；使用真实正式 API 与 Python 子进程，不启动主项目服务、不连接 ADB 或外部模型，不改写用户现有数据库。已有编译器的手机动作和匹配仍是日志式占位，本版不声称真实手机动作验收。
- 保留原型 v1/v2 和已有其他任务改动。未修改正式 VERSION，未提交、推送、标签或部署；发布按后续授权处理。
