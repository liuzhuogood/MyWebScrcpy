# v1.18.0-feature 版本说明：脚本管理布局与多设备配置

日期：2026-10-11。状态：正式实现与隔离环境验收完成。

1. 文档助手放到右侧；源码、Markdown 预览和 Python 产物合并为一个内容区，通过底部标签切换。
2. 左侧任务栏承载新建与任务选择，直接显示标题、设备、版本、定时、超时、启用、下次执行、最近结果和 Python 版本。
3. 新建时必选目标设备，支持多选。请求、响应和持久化统一使用设备数组，Markdown 不再提供目标设备。
4. 模板库汇总已选设备与公共模板，按 ID 去重并展示归属；每台执行设备分别校验模板，不替换同名资产。
5. 手动与定时使用同一执行入口，分别管理设备进程、互斥、超时、终止及结果。设备变更作用于后续启动，明确批次避免旧结果覆盖新运行。
6. 明确单设备迁移为单元素列表；auto、空值或冲突任务待配置并停用。迁移保留文档原文，旧字段由用户明确移除，重新选择设备后仍需手动启用。
7. 保存失败保留输入，各任务保留草稿和助手会话；建议显式应用，迟到回复不覆盖其他任务或新修改。完整 Markdown 渲染清理可执行 HTML。

前端构建、全量 Go 测试、vet、受影响模块 race 检查及正式桌面/小屏浏览器验证通过，证据见 [设计文档](design.md#正式实现与验证证据)。Python 设备参数、独立终止和子进程超时均已真实验证。

手机动作与匹配仍沿用原有日志式占位，未验收真实手机动作。测试使用隔离数据，未升级用户数据库、启动主项目服务或发布部署；正式 VERSION 未改变；代码提交与推送按本轮「2」授权执行，实际提交结果以 Git 记录为准。
