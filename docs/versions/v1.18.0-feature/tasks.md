## 数据与功能实现

- ✅ 为 `target_devices` 设计明确的请求、响应与持久化结构，覆盖创建、更新、列表、详情和调度信息。
- ✅ 验证设备列表非空、重复、未知、迁移冲突和重开幂等；事务迁移保留旧列与原文。
- ✅ 新建要求填写标题并多选设备；保存失败保留草稿，切换任务避免丢失未保存修改。
- ✅ 将目标设备配置移出 Markdown 来源，同步新建示例、AI 提示词与生成内容；按确认策略处理旧解析逻辑。
- ✅ 按任务栏、统一内容区、右侧助手拆分页面，底部标签切换保留编辑与会话状态。
- ✅ 任务栏展示标题、设备列表、文档版本、定时、超时、启用、下次执行、最近结果、编译版本及逐设备运行状态；清理重复卡片与技术文案。
- ✅ 模板库加载所选设备和公共模板，按 ID 去重，展示归属；处理请求失败和切换设备时的迟到响应。
- ✅ 针对每台执行设备校验模板引用，不使用同名资产或相似字段猜测替换。
- ✅ 手动执行和定时调度共用已保存设备列表；对接逐设备启动、状态、终止、互斥与超时。
- ✅ 核对设备参数实际传入 Python；设备变更作用于后续触发，不改写正在运行实例的设备。
- ✅ 按边界添加关键流程、异常及外部调用日志，避免将日志说明写进产品界面。
