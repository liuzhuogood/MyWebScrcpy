# v1.3.0-feature 版本说明

1. 新增 `/files.html` 手机文件管理页面，支持目录层级、面包屑、搜索、类型筛选、排序、批量选择和响应式桌面/移动布局。
2. 新增 `/api/files/*` 文件管理接口，支持容量查询、上传队列、下载、移动、重命名、批量删除和当前进程内撤销。
3. 增加 `FILES_DIR`、`FILES_TOKEN` 和 `FILES_MAX_UPLOAD_BYTES` 配置；服务端执行 Bearer 鉴权、路径边界、符号链接和同名冲突校验，删除数据先进入 `.trash`。
4. 更新共享样式、设备列表入口、README 和版本设计文档，补充空目录、加载、错误、权限、冲突、上传和撤销状态。
5. 已完成 Go 单元/接口测试、路径安全测试、接口联调、JavaScript 语法检查及 Chrome 桌面/移动断点冒烟验证；正式提交和发布仍需用户确认。
