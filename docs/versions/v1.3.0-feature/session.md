## 会话

### 1. 用户

> 请设计手机文件管理页面。
>
> 目标是让用户能够直观地浏览、搜索、上传、下载、移动、重命名和删除自己的文件，并清楚了解文件夹层级、文件类型、大小、修改时间和存储空间使用情况。
>
> 请输出：
>
> 1. 页面信息架构和主要区域划分；
> 2. 桌面端页面布局，必要时补充移动端适配建议；
> 3. 文件列表、文件夹导航、搜索、筛选、排序和批量操作的交互方式；
> 4. 上传中、空文件夹、加载中、错误和删除确认等状态；
> 5. 面向普通用户的简洁中文界面文案；
> 6. 颜色、字体、间距、按钮和图标的视觉建议；
> 7. 关键组件清单，以及后续实现页面所需的 HTML/CSS 或前端框架建议。
>
> 请优先保证操作清晰、层级易懂、重要操作可撤销或二次确认。不要直接修改项目文件；如果缺少目标平台、技术栈或现有设计规范，请先列出假设并标明需要确认的内容。
