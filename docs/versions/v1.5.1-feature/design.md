# v1.5.1-feature 设计说明

## 背景

生产服务由 systemd 直接启动，工作目录为 `/`。相对录像路径导致普通服务用户无权创建 `/recordings`，录制启动返回 503。

## 目标

1. 录制在未配置目录时使用稳定、可写的用户缓存目录。
2. 首页仅保留面向用户的导航，并提供项目 GitHub 链接。
3. 在当前播放器页调整显示尺寸，不再通过原始尺寸模式跳转页面。

## 非目标

1. 不删除脚本管理 API 或页面，只隐藏首页入口。
2. 不以重启全局 ADB 服务来处理本次 503。

## 关键决策

1. `RECORDINGS_DIR` 仍优先；未配置时使用用户缓存目录，无法取得时回退到系统临时目录。
2. 显示尺寸滑道范围为原始画面的 25%～175%，100% 位于中点，并在其附近吸附。
3. 手动尺寸可滚动查看；“适应窗口”恢复既有自适应布局。

## 风险与回滚

缓存目录可能被系统清理，完成录像仍受保留期和配额控制。设置 `RECORDINGS_DIR` 可迁移到指定持久目录；回滚二进制即可恢复此前界面与默认目录行为。
