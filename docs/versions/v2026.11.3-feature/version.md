# v2026.11.3-feature 版本说明

## 1. 版本定位

- 本版为按北京时间日期的例行发布，包含 `v2026.11.2` 的全量能力与发布加固。
- 重点落地首页全局操作面板重构、设备卡片 0 间隙顶格排布、三大连续滑动调节以及多设备实时同步操作功能。
- 版本号全量同步：`VERSION`、`frontend/package.json`、`desktop/package.json`、`desktop/tauri.conf.json`、`desktop/Cargo.toml`、`desktop/Cargo.lock`、`packages/python-sdk`（pyproject、`__init__.py`、`version.go`）统一为 `2026.11.3`。

## 2. 功能范围

1. **首页右侧“操作”面板重构与全局控盘**：
   - **面板定位与更名**：原右侧“批量操作面板”正式更名为“操作”面板，提升为首页全局统一控制中枢。
   - **两态平滑折叠**：
     - **展开态 (Expanded，宽约 320px)**：收纳设备搜索、视图模式、连续滑动调节组、编号显隐网格（01..N）与四键纯图标动作组；
     - **收起态 (Collapsed，宽 52px 极窄侧边条)**：停靠右侧，包含展开把手按钮（`<PanelRightOpen>`）、快捷搜索展开、快速刷新、视图直切与已选设备 Badge，文字纵向竖排“操 作”。
   - **界面纯净化与交互减负**：去除搜索框冗余标题，去除面板底部冗余历史反馈长列表，批量操作改为轻量即时 Toast 反馈；顶栏数量胶囊迁移至“设备显隐”旁。
   - **批量动作纯图标化与“同步操作”**：动作按钮彻底纯图标化，Hover 展示功能说明；新增“同步操作”模式，操控单机即可将触控与按键实时同步至全量已勾选设备。
2. **去除顶部大横条，实现卡片顶格**：
   - 彻底移除原 `HomeControlCapsule` 大横条与设备列表区冗余筛选提示条，大幅释放首屏垂直可用空间。
   - 左侧设备卡片从容器最顶端 0 间隙直接顶格排布，视觉视野纯粹开阔。
3. **升级为三大连续滑动调节与视图精简**：
   - 视图模式精简为“卡片视图 (`deck`)”与“手机视图 (`phone`)”。
   - **手机大小 (Scale)**：70% ~ 140%（对应卡片基准宽 190px ~ 380px，默认 270px 100%），左侧网格实时无级缩放并流式重排；
   - **投屏码率 (Bitrate)**：2 Mbps ~ 16 Mbps（流畅 2M / 标清 4M / 超清 8M / 极致 16M）；
   - **投屏质量 (Quality)**：50% ~ 100%（720P / 1080P / 2K超清 / 100%原画）。
4. **手机卡片紧密网格与遥测感知**（沿用加固）：
   - `HomePhoneView` 支持 `viewMode='deck'|'phone'`，共用紧密设备墙规格，1:1 无缝重合零断层。
   - 状态感知中心：免投屏感知黑屏休眠与锁屏，亮屏展示前台运行应用专属彩色图标与中文名称。
   - 虚拟滚动与遥测感知支撑海量设备流畅渲染。
5. **CI/CD 与环境兼容性加固**：
   - 严格遵循 SemVer 规范，不含前导零（`2026.11.3`）。
   - Python SDK 发布工作流依赖与版本校验加固。

## 3. 验证与交付

- 版本一致性：`node scripts/sync-version.mjs --check` 与 `node --test scripts/sync-version.test.mjs` 本地通过。
- 自动化测试：`go test ./...` 单元测试通过，`pnpm --dir frontend build` 构建通过。
- 发布链路：推送 tag 后由 `Build and Release` 工作流完成五平台 CLI、Windows 签名桌面包、macOS DMG、Release 资产与 Docker 镜像；Python SDK 由 `Publish Python SDK` 工作流发布至 PyPI。
