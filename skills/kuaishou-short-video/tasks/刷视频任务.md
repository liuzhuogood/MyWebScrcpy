# 刷视频任务流程

本文档定义快手极速版“看视频得金币”任务的执行流程与状态流转。

## 流程图

```mermaid
flowchart TD
    Start([开始任务]) --> Step1[定位至任务中心页面]

    Step1 --> Step2[指定区域 OCR 识别<br/>BBox: x:19, y:365, w:420, h:85]

    Step2 --> Step3{OCR 结果解析}

    Step3 -->|解析失败 / 未识别| RetryOCR{重试次数 < 3?}
    RetryOCR -->|是| WaitOCR[短暂等待 / 微调滚动] --> Step2
    RetryOCR -->|否| Fail([任务异常退出 / 报警])

    Step3 -->|解析成功| ParseData[提取数据:<br/>1. 已领金币: 3878<br/>2. 当前进度 / 目标: 3878 / 7852<br/>3. 识别按键文案]

    ParseData --> CheckComplete{进度是否已完成?<br/>current >= target}
    CheckComplete -->|是 / 已达上限| Done([任务完成])

    CheckComplete -->|否 / 待继续| Step4[点击区域内『去看视频』文字位置]

    Step4 --> Step5[跳转至短视频信息流]

    Step5 --> Step6[执行刷视频流程<br/>拟人化随机滑动 / 停留 5~15s / 监测红包进度]

    Step6 --> Step7{单轮刷视频批次完成?}
    Step7 -->|否| Step6
    Step7 -->|是| Step8[执行返回操作<br/>退出视频流返回任务中心]

    Step8 --> Step9[等待任务中心页面加载/刷新]
    Step9 --> Step2
```

## 详细步骤说明

### 1. 任务中心 OCR 识别与数据解析
- **目标区域（Bounding Box）**：
  - `{"x": 19, "y": 365, "width": 420, "height": 85}`
- **示例 OCR 文本**：
  ```text
  已领3878金币，继续看视频得金币
  3878/7852
  去看视频
  ```
- **字段提取与正则匹配规则**：
  - **已领金币**：`已领(\d+)金币` -> 提取数值（如 `3878`）
  - **任务进度**：`(\d+)/(\d+)` -> 提取 `current` (`3878`) 与 `target` (`7852`)
  - **完成判断**：
    - 若 `current >= target` 或 文案为“已完成”/无“去看视频”按钮，则标记该任务完成。

### 2. 触发“去看视频”
- **定位**：在指定区域 `{"x": 19, "y": 365, "width": 420, "height": 85}` 内命中“去看视频”字样对应的子区域坐标，或点击按钮默认锚点。
- **动作**：触发 Tap 点击事件，等待页面跳转进入短视频播放流。

### 3. 刷视频流程执行
- 调用通用短视频消费动作（如 `watch_video.py`）。
- 每条视频拟人化停留 5 ~ 15 秒，随机执行轻微上下滑动与金币轮盘进度监测。
- 按设定批次（如刷 5~10 条或看满特定时长）为一周期。

### 4. 返回并复核进度
- 调用 `try_return.py` 或返回键，回到“任务中心”。
- 重新触发第 1 步 OCR 识别，比对 `current` 进度增长情况与完成状态。
- 若进度已达标则结束任务；否则进入下一轮循环。
