# 流程与边界

```mermaid
flowchart TD
 A[核对服务、设备并唤醒] --> B[打开快手极速版]
 B --> C[异步红包守护30秒]
 C --> D[回收线程并进入去赚钱]
 D --> E[连续打卡白拿手机]
 E --> F{签到状态}
 F -->|去签到| G[点击，30秒内等待打卡成功]
 F -->|仅已签到| H[记录本日已签到]
 G -->|未出现打卡成功| X[保留失败证据，返回并失败退出]
 G -->|成功| I[返回任务列表]
 H --> I
 I --> J{连续签到同一行有去看视频}
 J -->|有| K[确认顶部生活、关注、发现]
 K --> L[观看120秒，每15到30秒随机上滑]
 L --> M[点击去赚钱并验证返回]
 J -->|无| N[记录实际可见状态]
```

“超时30秒”解释为启动后弹窗监测总窗口。关键词严格使用用户给出的 `遊好友得大额红包`；出现且同屏“去领取”唯一时点击，随后确认消失，不盲目重发动作。

守护仅一个线程，识别、点击串行，不积压任务。主流程等待线程回收才换页；旧结果不跨阶段使用。签到或观看期间不继续抢占点击。

只执行这两个任务。登录、验证码、支付、下载、分享或其他任务出现时停止；已确认弹窗可以由视觉接管关闭，不点击分享/领奖广告入口。
