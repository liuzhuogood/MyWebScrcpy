# 验证与报告

1. **真实业务验证**：
   - 动作执行后以实际页面和业务结果确认。
   - 报告明确区分：本次打卡成功、本日已签到、签到失败。
   - 连续签到明确区分：当前未见入口、当前不要求视频、已观看并返回、平台仍未认定签到。
   - 外部进程退出码 0 不能代替业务结果。

2. **产出与证据记录**：
   - 所有任务执行过程中的日志、报告、截图与视频均写入本地任务工作目录 `~/.mywebscrcppy/tasks/<task-id>/`。
   - 任务定义与产出契约按 `task.json` 声明读取，不向云端或旧接口上报。
   - 截图与日志保留必要业务关键帧，清理本次无用临时文件。
