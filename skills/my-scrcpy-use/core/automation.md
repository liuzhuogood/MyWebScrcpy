# 自动化脚本规范

1. 遵循[入口 API 规则](../SKILL.md)，优先复用 [Python SDK](../../../packages/python-sdk/README.md) 的公开方法，缺少能力时用 curl；不猜接口、字段或 SDK 方法。
2. 按[环境规范](env.md)读取服务地址、`serial` 和执行目录，显式传入 SDK；运行产物均写入本次执行目录。先确认流程和成功条件，仅编写脚本时不操作实机，执行限于用户授权范围。
3. 每步按“识别页面 → 唯一定位 → 操作 → 验证”执行；使用当前快照，页面关联、XPath 与坐标校验见 [UI XML 规范](ui-xml.md)。快照失败、页面冲突或多匹配时停止，不使用旧数据。同一设备串行操作。
4. 等待设置截止时间和轮询间隔，单次请求不超过剩余预算；只读请求可有限重试，动作结果不明时先查实际状态，不盲目重发。
5. 按采集、定位、动作、验证拆分必要函数，退出时释放资源；记录步骤、耗时和错误，失败或结果未知时保留证据并非零退出，日志不含凭据。
6. 验证正常流程及快照失败、定位异常、超时等关键分支；实机执行后用新页面或业务结果确认完成，交付运行命令、证据与未验证范围。
7. 需要任务面板上报时参考[任务上报规范](task-reporting.md)。
