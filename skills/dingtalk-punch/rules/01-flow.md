# 钉钉打卡流程与业务边界

## 执行流程

1. **前台与定位检查**：
   - 打开定位辅助应用设置目标经纬度并核对逆地理编码（如必须包含“长沙”）。若城市不匹配立即终止，防止误打卡。
2. **进入打卡页面**：
   - 发送 `KEYCODE_HOME` 回到桌面。
   - 通过 OCR 或 XML 点击钉钉桌面小组件中的“去打卡”入口（`com.alibaba.android.rimet:id/tv_attendance`）。
3. **识别并点击打卡按钮**：
   - 轮询等待“上班打卡”或“下班打卡”按钮（上限 60 秒）。
   - 若检测到“不在考勤范围”等异常提示则提前终止。
   - 匹配到打卡按钮后，点击按钮中心。
4. **校验打卡结果**：
   - 抓取打卡后页面全文 OCR，检测“打卡成功”、“已打卡”及打卡时间。
