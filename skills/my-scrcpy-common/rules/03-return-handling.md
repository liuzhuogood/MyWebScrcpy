# 尝试返回与键值处理规则

1. **ESC 与 BACK 区分**：
   - 消除临时弹窗、遮罩或关闭软键盘时，优先调用 `try_return.py`（发送 `KEYCODE_ESCAPE` 111）。
   - 执行真正的页面层级返回（如退回上一 Activity 或离开页面）时，调用 `android_back.py`（发送 `KEYCODE_BACK` 4）。
2. **返回证据确认**：
   - 发送键值前后对比观测。通过前台包名、Activity 或窗口标识变化判断页面切换；同页面弹层关闭需另行核对截图或明确的业务标志，不以 OCR 文本波动判定成功。
   - 仅凭像素变化或视频画面变动不能作为返回成功的证据。
   - 若无法判定是否成功，状态标记为“未知”，交由助手重新观察。
