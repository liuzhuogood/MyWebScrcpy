# 后台管理端 UI 规范

用于采用 shadcn、Tailwind 或类似组件体系的后台管理界面。已有品牌、组件和项目规范优先；本文件是项目风格约定，不代替组件库文档。

- 优先复用已有表格、表单、弹窗与导航组件，颜色和间距集中使用主题变量；同类操作保持相同位置与样式。
- 列表围绕查找、筛选、查看详情与处理记录组织。筛选条件、分页和选择状态在用户返回时尽量保留；大数据量使用项目已有分页方式。
- 表单使用清楚的字段名、必要说明和就近错误提示；提交后展示真实结果，处理中防止重复提交。
- 区分加载、空结果、无权限和请求失败；各状态给出适用的下一步，不统一显示“暂无数据”。
- 批量操作展示已选数量与范围，重要或不可撤销操作写清对象和后果；普通操作不增加无意义确认。
- 使用自然中文动作文案，业务状态与界面文案一致，不把技术字段或内部设计术语直接用作按钮名称。
- 表格保留清楚的列标题和数值对齐，长内容提供查看完整信息的方式；小屏允许合理横向滚动或转换展示。
- 保留键盘操作、可见焦点、控件标签及足够的文字对比度；状态不能只用颜色表达。

验证主要列表、筛选、编辑、提交失败与成功路径，检查小屏布局、键盘可操作性和主题一致性。
